## 📦 After Builds Complete

### **Download .aab Files**

```bash
# Customer App
cd /home/ubuntu/Desktop/GroomLink/apps/customer-app
eas build:download --platform android

# Partners App
cd /home/ubuntu/Desktop/GroomLink/apps/partners-app
eas build:download --platform android
```

### **Upload to Google Play Console**

1. **Create Customer App**
   - Play Console → Create App → "GroomLink"
   - Upload `.aab` file
   - Complete store listing
   - Submit for review

2. **Create Partners App**
   - Play Console → Create App → "GroomLink Partners"
   - Upload `.aab` file
   - Complete store listing
   - Submit for review
